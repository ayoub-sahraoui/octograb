# OctoGrab companion illustrations

Created: 11 October 2026.

Generated with the built-in image generation tool using the user-approved corrected mascot as the identity and style reference. The palette, rounded head, face, and outlined 2D style are shared with the brand mark.

## Delivered assets

| Asset             | Full PNG master                              | Optimized runtime asset                                   | Used in                                                |
| ----------------- | -------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| Blueprint builder | [PNG](./illustrations/blueprint-builder.png) | [WebP](../../public/illustrations/blueprint-builder.webp) | Empty editor and the editor with no selected blueprint |
| Blueprint library | [PNG](./illustrations/blueprint-library.png) | [WebP](../../public/illustrations/blueprint-library.webp) | Empty library and unmatched searches                   |

Both masters are transparent RGBA PNGs. Runtime illustrations are proportionally resized to 640 × 480 and exported as lossless WebP. These are decorative beside descriptive headings and actionable buttons, so they use empty alt text. No external image requests are needed.
